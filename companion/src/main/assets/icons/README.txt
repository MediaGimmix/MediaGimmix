MediaGimmix Remote (companion app) icons. Every file is optional: without it the built-in
Material icon is used. Put your own PNGs here with these names and rebuild.

  button_play.png          Play
  button_pause.png         Pause
  button_previous.png      Previous
  button_next.png          Next
  button_stop.png          Stop
  button_shuffle.png       Shuffle (shown dimmed when shuffle is off)

Volume (Player tab, ends of the volume slider):
  volume_down.png          one notch down
  volume_up.png            one notch up

Keep screen on (sun, right end of the tab bar):
  screen_on.png            recoloured white (on) / black (off), so any one-colour image works

Tabs along the top (the selected tab is full strength, the others dimmed):
  tab_player.png           Player
  tab_queue.png            Queue
  tab_playlists.png        Playlists
  tab_search.png           Search
  tab_settings.png         Settings

Notification (optional):
  notification.png         small icon of the media notification (white on transparent; Android tints it)
  button_close.png         the notification's close (✕) button
  The notification's other buttons use button_play/pause/previous/next.png above.

These are shown in their own colours, not tinted.
